# 🎮 PerguntaAí - Unity (Frontend)

Este repositório contém o **Frontend** desenvolvido em **Unity 6** para o projeto "PerguntAí", uma plataforma multijogador de quizzes interativos ao estilo do Kahoot.

Este projeto foi desenvolvido no âmbito da unidade curricular de **Tecnologias e Sistemas de Informação** do CTeSP de Programação no **IPMAIA (2025/2026)**.

## 👥 Equipa de Desenvolvimento
* **João Quaresma:** Desenvolvimento do Frontend (Unity) e Autenticação (Firebase).
* **Gonçalo Carvalho:** Desenvolvimento da API Backend (C# ASP.NET Core), Base de Dados e Alojamento Cloud.

## 🚀 O meu Papel no Projeto (Frontend & Autenticação)
Fui o responsável por todo o desenvolvimento do lado do cliente (Frontend), focando-me na criação da interface, mecânicas de jogo e segurança do utilizador.

**Principais responsabilidades:**
* **Desenvolvimento da UI/UX:** Criação de toda a interface visual do jogo (Ecrã de Login, Lobby de Espera, Ecrã de Respostas e Leaderboard).
* **Integração de Autenticação Segura:** Implementação de **Firebase Authentication** para garantir um registo e login de jogadores seguro e fiável.
* **Comunicação com o Backend:** Consumo da API RESTful e integração de WebSockets para garantir a comunicação em tempo real entre os jogadores e a sala de jogo.

## 🛠️ Stack Tecnológica Completa
**Frontend (Este Repositório):**
* **Game Engine:** Unity 6
* **Linguagem:** C#
* **Autenticação:** Firebase

**Backend & Infraestrutura (Repositório Externo):**
* **Backend API:** ASP.NET Core (C#)
* **Base de Dados:** PostgreSQL
* **Cloud Server:** Microsoft Azure
